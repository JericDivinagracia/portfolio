# Jeric Divinagracia – Portfolio

Static portfolio site (one `index.html`). Deploys to Render as a free Static Site.

## Deploy on Render
1. Create a new GitHub repository and upload `index.html`, `render.yaml`, and this README.
2. Sign in at https://dashboard.render.com and click **New → Static Site**.
3. Connect your GitHub account and pick the repository.
4. Settings: Build Command = (leave empty), Publish Directory = `.`
5. Click **Create Static Site**. Your site goes live at `https://<name>.onrender.com`.

Every push to the repository redeploys the site automatically.
