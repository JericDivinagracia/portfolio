What I can do for your team

From the first test plan to the final go/no-go call, I cover the full quality cycle.

Test automation

I design and maintain automated test frameworks with Cypress and Selenium that widen coverage and cut regression time.

Manual & functional testing

Functional, regression, sanity, and smoke testing, with clear test cases for new features and legacy flows.

API testing

I validate endpoints, payloads, and error handling with Postman, Swagger, and REST-based frameworks.

UAT coordination

I run user acceptance testing with business teams, escalate issues fast, and hand off cleanly to production support.

CI/CD quality gates

I plug automated tests into your pipelines for continuous testing and faster, safer releases.

Quality reporting

Defect tracking, root cause analysis, and clear quality metrics so everyone knows if a release is ready.

How I work

A simple, repeatable flow that fits into your Agile sprints.

  1. Review

    Read requirements and specs to make sure every story is testable.

  2. Plan

    Write the test strategy, test plan, and test cases.

  3. Test

    Run manual and automated tests across web and mobile.

  4. Report

    Log defects, find root causes, and work with developers on fixes.

  5. Release

    Give a clear go/no-go call based on results and risk.
